# عقد ربط ANTER Messenger بخادم ANTER

يستخدم ANTER Messenger حسابات ANTER الحالية ولا ينشئ حسابات موازية. يجب أن يضيف خادم Flask في مشروع ANTER واجهة API مخصصة للتطبيق قبل تفعيل الاتصال الحقيقي. لا يقبل التطبيق كلمة مرور في واجهة إعدادات الخادم، ولا يحمل مفتاح Groq أو مفاتيح الخادم.

| المجال | واجهة API المطلوبة | قاعدة الحماية |
|---|---|---|
| المصادقة | تسجيل دخول عبر متصفح النظام أو رمز قصير العمر، ثم إصدار access token وrefresh token | تحفظ الرموز فقط في Android Keystore عبر SecureStore؛ لا تُخزن كلمة المرور. |
| الحساب الحالي | `GET /api/mobile/v1/me` | يعيد المستخدم الحالي وحالة الربط فقط. |
| المحادثات | `GET /api/mobile/v1/conversations` | يعيد محادثات المستخدم المصرح له فقط. |
| الرسائل | `GET` و`POST /api/mobile/v1/conversations/{user_id}/messages` | يفرض المتابعة المتبادلة وقواعد الخصوصية على الخادم، لا في التطبيق فقط. |
| سجل المكالمات | `GET /api/mobile/v1/conversations/{user_id}/calls` | يعيد السجل للطرفين المشاركين فقط، من دون أي محتوى صوتي. |
| الإشارات | `POST /api/mobile/v1/calls/signals` وpoll أو WebSocket | يفرض أن الطرفين يتابعان بعضهما قبل العرض والقبول والإجابة. |
| الإشعارات | تسجيل Expo push token بعد المصادقة | لا يرسل الخادم إشعاراً قبل التحقق من ملكية الحساب والجهاز. |

> لا يُعامل التطبيق كبديل لقواعد الحماية الخادمية. يطبق Flask التحقق من المستخدم، والمتابعة المتبادلة، وCSRF أو رموز المصادقة المخصصة، والتحكم في الوصول في كل طلب حساس.
